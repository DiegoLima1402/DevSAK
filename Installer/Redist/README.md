# WebView2 Evergreen Bootstrapper

Place the official Microsoft bootstrapper here as:

`MicrosoftEdgeWebview2Setup.exe`

Download:

https://go.microsoft.com/fwlink/p/?LinkId=2124703

The DevSAK installer runs this file only when the WebView2 Runtime is not already present. A per-user DevSAK setup invokes it without elevation so the Runtime is installed for the current user.
